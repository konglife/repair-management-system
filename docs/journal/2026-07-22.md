- **ตัวตนของผม:** ผมระมัดระวังเรื่องกฎเหล็ก (แยก C4 ออกจาก C9 ชัดเจนเพื่อไม่แตะ DB) และยึด Matt flow (grill → design doc → implement) เหมือน issue อื่นที่ปิดไป — มันทำให้แต่ละ candidate มีโครงเดียวกัน ต่อกันง่ายข้ามแชท
