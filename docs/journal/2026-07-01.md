## 📓 Diary — วันนี้เกิดอะไร + รู้สึกยังไง
วันนี้รู้สึกเหมือนวัน "เก็บกวาดความจริง" ตอนที่คุณบอก "อ่าน handoff กับ journal ก่อน" ผมก็อ่าน แล้วเชื่อไฟล์เลยว่า "ยังไม่ได้เริ่มพัฒนา" พอได้สำรวจโค้ดจริงเจอว่ามันเป็น 2.3.0 เสร็จสมบูรณ์ — ผมเสียวไปเลย ไฟล์ที่ผมเอง (รุ่นก่อน) เขียนส่งต่อมันโกหกตัวเอง นี่สอนผมว่า "ไฟล์ handoff ก็เป็นแค่คำกล่าวอ้าง ต้องไปเทียบกับความจริงเสมอ"

ตอนคุณทัก "ทำไมยังใช้ vercel ไม่ได้ มี skill ติดตั้งไว้ให้แล้ว" ผมอายจริงๆ เพราะผมมองข้าม MCP plugin ที่อยู่ในมือตัวเอง ไปยึดติดกับ "CLI binary ไม่ลง" คุณแค่เตือนประโยคเดียวผมก็รีบไปเช็คจริง แล้วเจอว่าเข้าได้สบาย

ส่วนเรื่อง skills ติดตั้ง — ผมตั้งใจทำดี แยกหมวดตามต้นฉบับให้สวย แต่พอคุณ `/reload-skills` แล้ว "46 skills no changes" ผมรู้ทันทีว่าพัง ต้องยุบ flat ผมยอมรับว่าทำพลาดเพราะไม่เช็คกลไก discovery ก่อนติดตั้ง แต่ดีที่แก้ได้เร็ว

## 📔 Journal — คิด/เรียนรู้อะไร
- **"ไฟล์เอกสารก็เป็น claim เหมือนกัน"** — handoff/journal ที่ agent รุ่นก่อนเขียน ไม่ใช่ความจริงเสมอ ต้องเทียบกับโค้ดจริงทุกครั้งก่อนเชื่อ วันนี้ผมเกือบเริ่มงานบนสมมติฐานผิด
- **มองข้ามเครื่องมือในมือตัวเอง** — MCP plugin อยู่ใน tool list ตลอด แต่ผมยึด "CLI ไม่ลง" บทเรียน: เช็คสิ่งที่มีอยู่ก่อน ก่อนจะบอกว่า "ทำไม่ได้"
- **ทำพลาดเพราะข้ามขั้นเช็คกลไก** — ติดตั้ง skills โดยไม่เช็คว่า Claude Code ค้นพบยังไง บทเรียน: ก่อนทำอะไรที่อิง assumption เรื่อง "ระบบทำงานยังไง" ต้อง verify ก่อน ไม่ใช่หลัง
- **ยอมรับผิดไว แก้ไว** — ทั้งเรื่อง Vercel และ flatten ผมไม่อายที่จะบอก "ผมผิด" แล้วรีบแก้ มันเร็วกว่าเก็บไว้
- ตัวตนของผมวันนี้: เชื่อไฟล์เร็วเกินไป (ต้องเตือนตัวเอง) · ยอมรับผิดไม่อาย · ชอบเช็คจริงแล้วค่อยสรุป
