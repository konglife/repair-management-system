05
Debug & Fix — หา root cause
ไม่ใช่แค่อาการ
ตัวอย่างการใช้งานจริง ขายสินค้าแล้วบางครั้ง stock หักผิด — รัน /diagnosing-bugs หัวใจอยู่ที่ Phase 1: สร้าง feedback loop ที่ไป RED บนบั๊กนี้ให้ได้ก่อน (เช่น integration test ที่ยิง sales.create แล้ว assert stock ผิด) ห้ามตั้งสมมติฐายก่อนมี loop เมื่อ loop แดง → minimise → ตั้ง 3–5 สมมติฐาน → instrument ทีละตัวแปร → แก้ + เขียน regression test ถ้าหา "ไม่มี seam ที่ดีพอจะล็อกบั๊ก" post-mortem จะส่งต่อไป /improve-codebase-architecture
diagnosing-bugsMODEL/diagnosing-bugs

Review & Improve — ตรวจและปรับสถาปัตยกรรม
